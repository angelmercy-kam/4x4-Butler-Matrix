This project focuses on the **design, simulation, and analysis of a 4×4 Butler Matrix integrated with a four-element antenna array for beam steering at 2.8 GHz in the S-band**. The Butler Matrix was developed using microstrip technology on a Rogers 5880 substrate and consists of branch line couplers, crossovers, and 45° phase shifters to provide the required power division and phase progression. The individual components and the complete integrated structure were evaluated using S-parameters, reference impedance, VSWR, gain, H-plane radiation patterns, surface current distributions, and far-field analysis. The results demonstrate that exciting different input ports produces distinct beam directions, with an overall beam coverage of approximately **100°**, a bandwidth of about **0.6 GHz**, and a peak gain exceeding **10 dBi** in the reported antenna-array results. The single-layer configuration offers a relatively simple, low-cost, and easy-to-fabricate approach, making the proposed system suitable for applications such as **wireless communication, radar, and satellite systems**.
